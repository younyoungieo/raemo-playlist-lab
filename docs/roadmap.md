# raemo-playlist-lab 전체 로드맵

## 프로젝트 목표

래모(raemo) 유튜브 플레이리스트 데이터를 기반으로,
가사 한 줄 큐레이션 + 무드 기반 추천 시스템을 구축한다.
장기적으로는 사용자가 자신의 플레이리스트를 넣으면 무드를 분석하고 추천받는 서비스로 확장.

---

## Phase 1 — 데이터 파이프라인 ✅ 완료

**목표:** YouTube 플레이리스트 + 네이버 블로그 가사 → JSON 데이터셋

**결과물:**
- `data/datasets/{playlist_key}.json` × 44개
  - 23개 built (유효 데이터, 가사 있음)
  - 1개 mismatch (24_Aug_2nd, 마지막 트랙 가사 누락)
  - 20개 skip (24_May_1st 이전, 가사 미작성)
- `data/playlist_index.json` — 전체 44개 플레이리스트 인덱스

**핵심 인프라:**
- `src/ingest/` — YouTube(yt-dlp), Naver 블로그 크롤링 + 캐시
- `src/clean/` — 규칙 기반 가사 라인 정제
- `src/dataset/` — position join, Pydantic 스키마, 벌크 빌드
- `data/overrides/` — 수동 교정 레이어

---

## Phase 2 — 무드 기반 검색 시스템 🔄 진행 중

**목표:** "비 오는 날 혼자 듣기 좋은" → 관련 트랙 + 가사 한 줄 반환

**핵심 구성요소:**
- 임베딩 인덱스 (ChromaDB, 줄 단위)
- LLM 무드 자동 태깅 + 수동 교정 레이어
- 무드 쿼리 → 트랙 검색 CLI

→ 자세한 설계: [phase2-design.md](./phase2-design.md)

---

## Phase 3 — 서비스 확장 (미정)

**후보 방향 (우선순위 미결정):**

- **사용자 플레이리스트 분석**: YouTube URL 입력 → 무드 프로파일 생성 ("당신은 새벽-위로-인디 타입")
- **무드 자동 분류 고도화**: 에너지 × 감정방향 2D 자동 계산
- **웹 UI / API 서버**: 로컬 CLI → 외부 접근 가능한 서비스
- **플레이리스트 자동 생성**: 무드 입력 → 스토리 흐름이 있는 선곡 순서 출력

**선행 조건:** Phase 2 로컬 검증 완료 + 데이터셋 확충 (skip 20개 가사 추가 또는 새 플레이리스트)

## Phase 4 — 콘텐츠 산출물 (백로그)

- 자동 업로드 (YouTube Data API v3)
